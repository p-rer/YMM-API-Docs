# プラグインを公開する
プラグインを制作しても、公開をしなければ使ってもらうことはできません。
この記事では公開方法をパターン別に紹介します。

## 公開する方法
公開には主に以下のプラットフォームが使用されています。
- Booth
- GitHub
> [!Tip]
> 情報発信にはXを使用するのが一般的です。
> Xでの宣伝の際は#ymm4pluginと#ymm4をつけることが推奨されています。

### Boothでの公開
1. [Booth](https://booth.pm/)にアクセスし、ログインする。アカウントがない場合は新規作成の必要があります。
2. 画面右上の自分の名前またはアイコンを押し、商品管理に移動。
3. 「＋商品登録」ボタンを押す。
4. 右の「デジタルデータを販売したい」の「『ダウンロード』商品を登録」をクリック。
5. 項目を入力する[^1]。カテゴリはソフトウェア、タグにはymm4とymm4pluginタグを追加するのがおすすめです。
6. 作品ファイル（.ymmeファイル）をアップロードする。この際、Boothが.ymmeに対応していないため、zipファイルに包んでからアップロードしてください。
7. 項目を全て埋めたら「公開で保存する」をクリックして公開が完了します。
   
### GitHubでの公開
1. [GitHub](https://github.com/)にアクセスし、ログインをしていない場合はログインする。
2. 画面右上の「＋」ボタンをクリックし、「New repository」を選択。
3. 項目を入力する[^2]。現時点では.ymmeファイルはアップロードしない。
4. 「Create repository」をクリック。
5. リポジトリのページに遷移します。右側の「Releases」にある「Create a new release」をクリック。
6. Tagをクリックし、「Create new tag」からバージョンを入力してください。タイトルもバージョンにすることが推奨されます。
7. プラグインの使い方などの説明を書く。説明文章にはマークダウンが使用可能です。任意で使用してください。
8. 「Attach binaries by dropping them here or selecting them.」をクリックし、.ymmeファイルをアップロードします。
9. 「Publish release」をクリックして公開が完了します。
>[!Note]
> ソースコードを公開する場合はgitリポジトリーをGitHubのリモートにpush、あるいはコードアセットをアップロードする必要があります。

[^1]: 価格について: YMM4プラグインを有料で販売している例は現状少ないです。好ましくないわけではなく、禁止されてもいませんが、ダウンロード数が減るのは覚悟の上で公開してください。

[^2]: LICENSEはソースコードを公開するか否かで分かれますが、公開する場合は任意のLICENSEを追加してください。ソースコードを公開しない場合はNo LICENSEで構いません。使用しているライブラリに合わせて、使用できないLICENSEがあるため、注意が必要です。
