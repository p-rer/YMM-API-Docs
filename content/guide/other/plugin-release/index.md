# プラグインを公開する
プラグインを制作しても、公開をしなければ使ってもらうことはできない。
この記事では公開方法をパターン別に紹介する。

## 公開する方法
公開には主に以下のプラットフォームを使用するのがよい。
- Booth
- GitHub
> [!Tips]
> 情報発信にはXを使用するのが一般的。

### Boothでの公開
1. [Boothにアクセス](https://booth.pm/ja)し、ログインする。アカウントがない場合は新規作成の必要がある。
2. 画面右上の自分の名前またはアイコンを押し、商品管理に移動。
3. 「＋商品登録」ボタンを押す。
4. 右の「デジタルデータを販売したい」の「『ダウンロード』商品を登録」をクリック。
5. 項目を入力していく。カテゴリはソフトウェア、タグにはymm4とymm4pluginタグを追加するのがおすすめ。
6. 値段についてだが、YMM4プラグインを有料で販売している例は現状少ない。好ましくないわけではないし、禁止されているわけでもないが、ダウンロード数が減るのは覚悟の上で公開することをおすすめする。
7. 作品ファイル（ymmeファイル）をアップロードする。この際、Boothがymmeに対応していないため、7zipなどでzipファイルに包んでからアップロードする。
8. 項目を全て埋めたら「公開で保存する」をクリック。
9. これにて公開は完了。
   
### GitHuubでの公開
1. [GitHubにアクセス](https://github.com/dashboard)し、ログインをしていない場合はログインする。
2. 画面右上の「＋」ボタンをクリックし、「New repository」を選択。
3. Boothと同様に項目を埋める。現時点では.ymmeファイルはアップロードしない。
4. Add READMEはONにする。
5. LICENSEはソースコードを公開するか否かで分かれるが、公開する場合は任意のLICENSEを追加する。ソースコードを公開しない場合はNo LISENCEでOK。
6. 項目を埋めたら「Create repository」をクリック。
7. リポジトリのページに移るので、右側の「Releases」にある「Create a new release」をクリック。
8. Tagをクリックし、「Create new tag」でバージョンを入力。
9. タイトルもバージョンにするのがおすすめ。
10. 説明にはマークダウンが使用可能なので、任意で使う。
11.  「Attach binaries by dropping them here or selecting them.」をクリックし、ymmeファイルをアップロード。GitHubはboothと違いymmeファイルに対応しているため心配する必要はない。
12. 最後に「Publish release」を押して公開は完了。
>[!Note]
> ソースコードを公開する場合はgitをpushする必要がある。こちらについては各自で調べていただきたい。
   
### Xでの宣伝の際の注意
Xでの宣伝の際は#ymm4pluginと#ymm4をつけるのがおすすめ。
これによって検索が容易になり、見つけてもらえる確率がアップする。
また、饅頭遣いさんがリポストをしてくださる場合もある。
